# SQL Learning Resources

This file contains useful documentation, references, and practice links for SQL learning.

## Official documentation

- PostgreSQL: https://www.postgresql.org/docs/
- MySQL: https://dev.mysql.com/doc/
- SQL Server: https://learn.microsoft.com/en-us/sql/
- SQLite: https://www.sqlite.org/docs.html

## SQL practice sites

- SQLZoo: https://sqlzoo.net/
- LeetCode SQL: https://leetcode.com/problemset/database/
- HackerRank SQL: https://www.hackerrank.com/domains/sql
- Mode SQL Tutorial: https://mode.com/sql-tutorial/

## Core topics to practice

- SELECT and filtering
- JOINs and relationships
- GROUP BY and HAVING
- Subqueries and CTEs
- Window functions
- Date and time functions
- String functions
- CASE expressions
- NULL handling

## Good habits

- Write clear, readable SQL
- Test small parts of a query before expanding it
- Keep notes on mistakes and corrections
- Verify logic against expected output
- Prefer understanding over memorization
